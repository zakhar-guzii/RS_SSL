     Plan: Baseline CNN for Merged HAR Dataset

     Context

     The project already has a CNN-LSTM model trained on UCI HAR
     (src/encoder.py). We need a simpler baseline: a pure CNN (BatchNorm +
     MaxPool) trained on the merged 4-dataset file data/merged/har_merged.npz
     (61,891 windows, 5 classes, 3 channels). Primary metric to monitor is F1
     Macro (tracked per epoch on validation, used for early stopping, and logged
     on test set). The new code must follow the exact patterns in
     src/encoder.py.

     ---
     Files to Create

     1. configs/datasets/har_merged.yaml

     Dataset config following the pattern in configs/datasets/uci_har.yaml:
     - dataset.name: "har_merged"
     - dataset.paths.root: "./data/merged/har_merged.npz" (single .npz file)
     - dataset.specs.num_classes: 5
     - dataset.specs.num_samples: 61891
     - input_format.channels: 3 (only accelerometer)
     - input_format.sequence_length: 128
     - Activity labels: {0: "downstairs", 1: "sit", 2: "stand", 3: "upstairs", 
     4: "walk"}
     - Split: train=0.7, val=0.15, test=0.15, stratified, seed 42

     2. configs/models/baseline_cnn.yaml

     Model config following the pattern in configs/models/cnn_lstm.yaml:
     - model.name: "baseline_cnn"
     - CNN: input_channels=3, conv_out_channels=[64, 128, 128], kernel_size=5,
     padding=2, pool_kernel=2
     - Classifier: num_classes=5, hidden_dim=64
     - training.batch_size=64, num_epochs=50, patience=10
     - mlflow.experiment_name: "HAR_Merged_Baseline_CNN"

     3. src/baseline_cnn.py

     Training script following src/encoder.py exactly. Functions in same
     order/signature:

     LABEL_NAMES — ["downstairs", "sit", "stand", "upstairs", "walk"]

     set_seed(seed) — copy from encoder.py

     plot_confusion_matrix(y_pred, y_true, path) — same as encoder.py, uses
     local LABEL_NAMES

     MergedHARDataset(Dataset) — new Dataset class for .npz:
     - Constructor takes X (np array), y (np array), normalizes with provided
     mean/std
     - __len__, __getitem__ returning (float32 tensor, long tensor)
     - Static method to load and normalize: caller computes mean/std from train
     split

     CNNClassifier(nn.Module) — the baseline model:
     Conv1d → BatchNorm1d → ReLU → MaxPool1d   (×3, channels: 3→64→128→128)
     AdaptiveAvgPool1d(1) → Flatten
     BatchNorm1d → Linear(128, 64) → ReLU → Dropout → Linear(64, num_classes)
     - forward(x): transposes (B, T, C) → (B, C, T) before conv (same as
     encoder.py)

     load_and_prepare_data(config):
     - np.load(npz_path), extract X, y
     - Stratified train/val/test split with train_test_split (two-step: first
     test out, then val out of train)
     - Z-score normalize using train mean/std only
     - Wrap in MergedHARDataset, create DataLoaders

     build_model(config, device) — instantiate CNNClassifier from config,
     .to(device)

     train_epoch(model, loader, optimizer, criterion, scheduler, device, mlflow,
     epoch):
     - Identical structure to encoder.py: tqdm loop, log train_loss and
     train_accuracy per epoch

     evaluate(model, loader, device) — identical to encoder.py, returns (preds, 
     labels) np arrays

     train_model(model, train_loader, val_loader, config, device, mlflow):
     - Same structure as encoder.py but early stopping monitors val_f1_macro
     (not val_acc)
     - Logs both val_f1_macro and val_accuracy per epoch

     evaluate_and_log(model, test_loader, device, mlflow):
     - Same as encoder.py: balanced_accuracy, f1_weighted, f1_macro, per-class
     F1
     - Logs classification_report.txt and confusion_matrix.png artifacts

     log_model_to_mlflow(model, test_loader, device, mlflow) — identical to
     encoder.py

     run_cnn_baseline() — entry point:
     config = ConfigLoader().load_experiment("har_merged", "baseline_cnn")
     - Same header print block, same MLflow param logging pattern as encoder.py
     - Logs: dataset params, training params, model arch params (input_channels,
     conv_channels, num_classes, dropout)

     ---
     Verification

     1. cd src && python baseline_cnn.py — should train without error, print
     epoch progress
     2. Check MLflow UI (mlflow ui) → experiment HAR_Merged_Baseline_CNN →
     verify val_f1_macro, test_f1_macro metrics appear
     3. Confirm early stopping triggers on val_f1_macro (not accuracy)
     4. Verify classification_report.txt artifact lists all 5 classes
